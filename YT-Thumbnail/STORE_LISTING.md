# Chrome Web Store Listing Draft

## Name

YT Thumbnail Peek

## Short description

Preview the current YouTube video's thumbnail from a small hover button beside the title.

## Detailed description

YT Thumbnail Peek adds a small, lightweight hover target to YouTube watch pages. Move your mouse over the icon beside the video title to instantly see the video's thumbnail without leaving the page.

The extension is intentionally simple:

- Works on YouTube watch pages.
- Shows the best available public YouTube thumbnail for the current video.
- Does not require an account.
- Does not collect or store personal data.
- Does not add analytics, tracking, or background network services.

## Category

Productivity

## Language

English

## Single purpose

Show the current YouTube video's public thumbnail when the user hovers over the thumbnail peek button beside the video title.

## Privacy Answers

Data collection: The extension does not collect, sell, share, or store user data.

Purpose: The extension reads the current YouTube video ID from the page URL only to construct the public thumbnail image URL displayed in the page.

Permissions justification: The extension runs only on `https://www.youtube.com/*` so it can add the thumbnail peek button to YouTube video pages.

## Test Instructions

1. Install the extension.
2. Open any YouTube video watch page.
3. Hover the small thumbnail icon at the right side of the video title.
4. Confirm that the video's thumbnail preview appears.
